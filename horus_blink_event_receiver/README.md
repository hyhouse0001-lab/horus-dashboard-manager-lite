# HORUS Blink Event Receiver

Independent fallback for the existing Alexa doorbell routine. Uses CoreyHayward/ha-blink-live-events v0.1.4's ARM64 receiver and its durable delivery worker, with a narrow in-process adapter rather than installing its additional Home Assistant custom component. No camera integration replacement, no dashboard changes, no Home Assistant Core restart. Only the existing script.horus_doorbell_live_view can be called. The app is isolated, has no exposed host port, uses admin-only ingress, and does not map HA configuration.

Install in the existing HORUS app store, start, open Web UI, choose Authorize Blink, follow the Blink-hosted sign-in link, and paste the callback only into the app's private field. No password or MFA is requested by HORUS. After authorization, test a physical press and a motion-only event. Logs should show FCM connection and a successful delivery; check the script's last_triggered and kiosk visually. Then enable Start on boot. Alexa remains unchanged. Stop/uninstall this app to roll back.

This is an experimental unofficial cloud push receiver, not a guarantee of independent physical notification generation: Blink itself can suppress notifications. It accepts a missing camera name because the household currently has one Blink doorbell; if another is installed, revisit scoping. Eight-second coalescing with Alexa may intentionally ignore repeated presses during that interval. Rejects stale receipts, non-doorbell events, and malformed IDs. Upstream keeps private raw push history and registration state under /data/horus-blink; protect backups, monitor storage, and do not publish logs. Token re-registration may be required. Build and physical tests must pass before relying on this backup.
